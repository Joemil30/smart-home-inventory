# Recipe artwork — v62

Thirteen new images were generated using the **built-in image generation tool**, then optimized into 960-pixel-wide WebP assets. No competitor screenshot or branded artwork was copied into the app. The existing chicken-spinach-pasta.webp is retained from v60.

These are illustrative serving images, not photographs of a user's household or proof of recipe testing. Built-in recipe detail discloses the generated-image status. The app's ingredients and directions, not the picture, define the recipe.

## Prompt set

Shared art direction: `photorealistic-natural`; original Stocked recipe-cover imagery; appetizing achievable home cooking; premium editorial food photography; natural window light; restrained pale stone/linen setting; realistic texture and color; centered dish suitable for landscape 3:2 and square cropping; no text, logos, hands or collage. One generated image per dish.
